THE THIRD DIMENSION MATTERS

上下两层，也是包围的一部分。

01 / 相邻

三条轴，六个方向

只沿 x、y、z 中的一条轴走一步。对角线不相邻，边界不环绕。平面内四面围住，还可能有上、下两气。

02 / 包围

跨层连通，整块提子

相邻同色子组成棋块，共享全部不同空点构成的气。落子先提敌方无气棋块，再检测自己；禁自杀，禁重现曾有的棋盘。

03 / 终局

共同确认，按面积计分

连续两次停着后，双方协商死活，点棋块标记死子。活子 + 仅接触本方的空域为面积；提子不另加分。电脑不裁定死活。
